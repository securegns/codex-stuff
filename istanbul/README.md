# Istanbul, Unhurried

A personalised, view-first Istanbul guide for September 9–12, 2026, starting from Vizyon Hotel Center. Includes 18 places, two real image previews per entry, collapsible tables, quietness and time-of-day filters, Maps directions, saved places, day routes, six food stops, drink guidance, and research sources.

## Files

- `index.html`: responsive layout, styling, practical notes.
- `data.js`: researched places, attributed external photos, sources, and dated itinerary.
- `app.js`: filters, favorites, photo viewer, day switching, Leaflet/OpenStreetMap route map and schematic fallback.

Open `index.html` in a modern browser, or serve this folder with any static web server. JavaScript is required for the place tables and itinerary. External photographs and interactive map tiles require an internet connection. The map connects approximate stop locations; it is not navigation. Maps links provide leg-by-leg directions.

## Verification and limitations

Research checked September 5, 2026. The desktop and mobile interface, all 18 entries / 36 image-preview slots, search, quiet filter, favorites, day changes, collapsible categories and map fallback were tested locally in Chromium. No script errors or horizontal overflow were detected at 1440px and 390px widths. The execution environment could not load external images or map tiles; those sources were inspected separately using the research browser. The public CDN URL could not be live-verified because that browser blocked the newly created URL. GitHub confirmed the public source-file commits.

Official schedules and venue pages are linked within the guide. Quietness, ideal visiting windows and travel durations are editorial estimates, not live crowd or transport data. Some hours, foreign ticket prices, gate policies and menu details remain unconfirmed and are labelled. No reservations, purchases or transfers have been made.

Photographs remain the property of their credited owners. Some are archival or small visitor previews. Context photos are labelled rather than represented as the exact view from a particular seat or boat. Public Maps galleries could not be exhaustively reviewed.

## Privacy

This public guide includes the hotel base and travel dates requested for the itinerary, but no personal name, booking reference, email or live location. A no-index directive is not access control. Saved places and checklist ticks stay in the visitor's browser storage.
